# 🏁 Obby Showdown (UNFINISHED)

Obby Showdown is a competitive multiplayer obstacle-course racing game built on the Roblox platform. Players face off in fast-paced 1v1 up to 4v4 battles, utilizing advanced movement mechanics and strategic abilities to cross the finish line first. 

---

## 🎮 Game Flow
1. **The Lobby:** Players gather in a central lobby and enter designated queue circles.
2. **Map Voting:** Once the queue fills, players vote on their preferred obstacle course.
3. **The Race:** Head-to-head racing where players use skill and speed to outpace opponents.
4. **Rewards:** Winning matches and setting fast completion times rewards players with coins.

## ✨ Core Features
* **Multiplayer Matchmaking:** Dynamic queuing for 1v1, 2v2, 3v3, and 4v4 match formats.
* **Strategic Abilities:** Use items mid-race (like throwing a banana peel to disrupt opponents) to gain a competitive edge.
* **In-Game Economy & Shop:** Spend coins on character abilities, custom cosmetics, and trails. Equipped cosmetics grant coin multipliers to accelerate progression.
* **Skill-Driven Progression:** Earn bigger rewards for faster completion times.
